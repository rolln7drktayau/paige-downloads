# Paige — téléchargements Windows

[**Télécharger Paige pour Windows x64**](https://github.com/rolln7drktayau/paige-downloads/releases/latest)

Application de travail sur les PDF : fusion, extraction, réorganisation, compression, annotations et signature visuelle. Traitement local des documents.

Ce dépôt contient les installateurs et les notes de version. Le dépôt de développement reste privé.

## Installation
Téléchargez `Paige-Setup-1.2.0.exe` dans la dernière version, puis lancez l’installateur. Le fichier `SHA256SUMS.txt` permet de vérifier son empreinte.

## Composants
L’installateur Windows x64 comprend les moteurs OCR, PDF et Office. Aucune installation manuelle de ces composants n’est nécessaire. L’installateur demande les droits administrateur pour installer le redistribuable Microsoft Visual C++. La signature visuelle n’est pas une signature numérique certifiée.
