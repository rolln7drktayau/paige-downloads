# Paige — téléchargements Windows

[**Télécharger Paige pour Windows x64**](https://github.com/rolln7drktayau/paige-downloads/releases/latest)

Application de travail sur les PDF : fusion, extraction, réorganisation, compression, annotations et signature visuelle. Traitement local des documents.

Ce dépôt contient les installateurs et les notes de version. Le dépôt de développement reste privé.

## Installation
Téléchargez `Paige-Setup-1.1.0.exe` dans la dernière version, puis lancez l’installateur. Le fichier `SHA256SUMS.txt` permet de vérifier son empreinte.

## Composants
qpdf est inclus. OCR, conversion Office et remplacement direct de texte nécessitent des composants externes ; consultez les notes de version. La signature visuelle n’est pas une signature numérique certifiée.
